## 记账

专注日常消费的 Android 离线个人账本。支持消费分类、月度账单、统计图表和本地备份恢复，无需登录。

最低支持 Android 8.0（API 26）。将 APK 下载到手机后打开安装；应用首次启动为空账本，预览中的消费仅用于测试。

仓库不包含个人签名私钥、签名密码、本机 SDK 配置或构建缓存。后续覆盖升级需要继续使用原发布密钥。
