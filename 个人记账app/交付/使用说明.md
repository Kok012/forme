# 《记账》使用说明

## 安装

1. 将 `交付` 文件夹中的正式 APK 传到自己的 Android 手机。
2. 使用系统文件管理器打开 APK；如果系统提示，允许当前文件来源安装应用。
3. 安装完成后，桌面应用名称为“记账”。首次打开是空账本，无需注册。

最低支持 Android 8.0。之后升级请使用同一个个人签名的新版安装包直接覆盖安装。不要先卸载旧版；卸载或清除应用数据会删除本机账本。

## 快速记一笔

进入“明细”，点击“记一笔”，输入消费金额，选择分类，检查日期后保存。默认日期是今天，备注可以不填。点击“保存并继续”可以接着记录下一笔。

大号数字键盘适合单手输入，也可切换系统键盘后粘贴金额。金额必须大于零，最多两位小数。首版只记录支出，不能录入负数退款。

点击已有消费打开详情，可以修改或删除。修改日期或分类后，所有相关月份和分类的统计一起更新。

## 查看每月消费

“明细”上方切换月份；点击月份可选择年、月。分类筛选只改变明细与筛选小计，月总额仍展示整个所选月的消费。

“统计”查看月度消费总额、分类占比和每日趋势，点击分类或日期可进入对应明细。消费较多时仍可按日查看，空月份不会显示示例数据。

## 管理分类

进入“设置 → 分类管理”，新增分类时填写名称、图标和颜色。用上下箭头调整常用分类顺序。

分类改名会更新历史记录的显示名称。归档后历史账单不受影响，新增消费时不再显示该分类；归档分类可以恢复使用。有消费记录的分类不能直接删除，内置“其他”始终保留。

## 备份与换手机

1. 在“设置”中导出完整备份。
2. 在系统文件选择器里选择手机本地目录或移动存储。
3. 等待应用提示导出成功，再将 JSON 文件另行保存到自己控制的位置。
4. 新手机安装“记账”，选择“从备份恢复”，选取该 JSON 文件。
5. 核对消费笔数、总额和日期范围，确认替换恢复。

恢复会替换当前全部账单和分类，不做合并。恢复前应用会保留一份私有快照，可在设置中撤销上次恢复；撤销也会替换当前账本，因此恢复后新记的消费应先按需导出。

备份文件是明文，包含消费信息。系统文件选择器可能展示云盘，选择本地存储即可保持导出过程离线。卸载、清除数据或丢失手机后，只有应用之外的完整备份才能帮助找回账本。

## 导出表格与主题

统计页可将所选月份导出为 CSV，用 Excel 等表格软件查看。CSV 不包含完整恢复所需的全部元数据，恢复请使用 JSON 备份。

在设置中选择浅色、深色或跟随系统。应用不访问网络，不自动抓取微信、支付宝或银行账单，消费需要自己记录。
