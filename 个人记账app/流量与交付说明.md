# 《记账》生成流量与交付说明

更新时间：2026-11-03。

首版已生成：`交付/记账-1.0.0.apk`，大小 **1,622,393 字节，约 1.6 MB**。传到手机时只需要安装包，不需要下载或复制整套开发工具；安装后的日常记账无需网络。

## 下载流量估算

继续开发前，本机已下载 Gradle 压缩包及 Android 软件包索引，合计约 **137 MB**。

在没有 Android SDK 和依赖缓存的情况下，从此处完成首版安装包预计还需 **1.2～2.5 GB** 下载流量：

| 内容 | 估算下载量 |
| --- | --- |
| Android 命令行工具、API 35 平台、Build Tools、Platform Tools | 约 300～600 MB |
| Android 构建插件、Kotlin、Compose、Room 等应用依赖，以及测试运行组件 | 约 900 MB～1.9 GB |
| Android 模拟器与系统镜像 | 本次不下载；如以后需要，通常另需约 2～4 GB |

以上是下载前的估算，实际会受缓存命中、依赖版本、重试及仓库响应影响。压缩包解压后的磁盘占用通常大于下载流量，建议开发电脑预留 **8～12 GB** 可用空间。

本次仅安装构建、测试和 APK 检查所需组件，优先复用已下载文件。为避免 Windows/Java 对中文构建缓存路径的兼容问题，开发工具与缓存现位于工作目录 `<workspace>\.jizhang-build-tools`，无需复制到手机。

生成后的应用日常使用完全离线，不包含网络权限。通过系统文件选择器导出时，请选择手机本地存储；若主动选择云盘，由对应文件服务使用网络。

## 最终交付位置

- `Jizhang/`：Android 原生工程、构建说明、测试代码和使用说明。
- `交付/`：构建成功后放置可安装的签名 APK 和校验信息。
- `私密签名/`：个人发布密钥及保存说明，应单独备份；不要随源码对外分享。

签名密钥用于今后覆盖升级。保持包名与签名一致，升级才可以保留已有账本。安装、卸载或清除数据前，请按需导出完整账本备份。
